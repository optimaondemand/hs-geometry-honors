📚 VOCABULARY

Algebraic Rule: A formula that describes how each point of a figure changes during a transformation.

Congruent: Figures that are the same size and shape with corresponding sides and angles equal.

Coordinate Plane: A two-dimensional surface formed by the intersection of a horizontal x-axis and a vertical y-axis.

Dilation: A transformation that enlarges or reduces a figure proportionally from a center point, usually the origin.

Image: The figure that results from a transformation of a pre-image.

Non-Rigid Motion: A transformation that changes the size of a figure, such as a dilation.

Origin: The point (0, 0) where the x-axis and y-axis intersect on the coordinate plane.

Pre-Image: The original figure before any transformation is applied.

Rigid Motion: A transformation that preserves distance and angle measure, such as a translation, reflection, or rotation.

Scale Factor: The number used to multiply the coordinates of a figure to make it larger or smaller in a dilation.

Similarity: When two figures have the same shape but not necessarily the same size; corresponding angles are equal, and side lengths are proportional.

Transformation: A change in the position, size, or shape of a figure.

Translation: A transformation that slides a figure a specific distance in a given direction.

Vector: A quantity with direction and magnitude that describes how far and in what direction to translate a figure.

💡 EXPLORING THE MATH

In today's lesson, we will explore how translations and dilations can be described using algebraic rules in the coordinate plane. You'll learn how to match the geometric movement of a figure with a coordinate-based rule, such as moving a shape left, right, up, or down, or resizing it using a scale factor. We'll focus on one transformation at a time—starting with translations—then progress to dilations. Through examples, algebraic representation, and graphing practice, you’ll become confident in both describing and applying these transformations.


Translation Rules and Algebraic Representations

Translation Right or Left:

A translation moves every point of a figure the same distance in the same direction.

\((x,y)\rightarrow (x+a,y)\)

where a is the number of units right or left (if negative).

Translation Up or Down:

A translation moves every point of a figure the same distance in the same direction.

\((x,y)\rightarrow (x,y+b)\)

where b is the number of units up or down (if negative).

Example:

\(\textcolor{red}{(x,y)\rightarrow (x+5,y)}\) - Translation Right 5 units

\(\textcolor{green}{(x,y)\rightarrow (x-7),y)}\) - Translation Left 7 units

Example:

\(\textcolor{purple}{(x,y)\rightarrow (x,y+4)}\) - Translation Up 4 units

\(\textcolor{orange}{(x,y)\rightarrow (x,y-6)}\) - Translation Down 6 units

Notice the coordinates of the figure:

\(A(-6,1)\rightarrow A'(-6+5,1)=(-1,1)\)

\(B(-6,6)\rightarrow B'(-6+5,6)=(-1,6)\)

\(C(-2,6)\rightarrow C'(-2+5,6)=(3,1)\)

\(D(-2,-1)\rightarrow D'(-2+5,-1)=(3,-1)\)

 

\(A(-6,1)\rightarrow A''(-6-7,1)=(-13,1)\)

\(B(-6,6)\rightarrow B''(-6-7,6)=(-13,6)\)

\(C(-2,6)\rightarrow C''(-2-7,6)=(-9,1)\)

\(D(-2,-1)\rightarrow D''(-2-7,-1)=(-9,-1)\)

Notice the coordinates of the figure:

\(A(-6,1)\rightarrow A'(-6,1+4)=(-6,5)\)

\(B(-6,4)\rightarrow B'(-6,4+4)=(-6,8)\)

\(C(-2,4)\rightarrow C'(-2,4+4)=(-2,8)\)

\(D(-2,-1)\rightarrow D'(-2,-1+4)=(-2,3)\)

 

\(A(-6,1)\rightarrow A''(-6,1-6)=(-6,-5)\)

\(B(-6,4)\rightarrow B''(-6,4-6)=(-6,-2)\)

\(C(-2,4)\rightarrow C''(-2,4-6)=(-2,-2)\)

\(D(-2,-1)\rightarrow D''(-2,-1-6)=(-2,-7)\)



Example 1

The triangle ABC is transformed to create triangle A'B'C' as shown.

Describe the transformation geometrically.

Represent the transformation algebraically.

Solution:

  • To describe the transformation geometrically, we need to observe what the triangle did from the preimage ABC to the image A'B'C'.
  • We notice that the vertices of the triangle slide to the left. This means it translated left a number of units.
  • Now, we need to count the units from point A to point A' to see how many units left it translated.
  • We count 4 units from point A to point A'.
  • Now, we can represent this algebraically using the rule for translations.

The triangle translated left 4 units represented as \((x,y)\rightarrow (x-4,y)\).

Example 3

The quadrilateral ABCD is transformed to create quadrilateral A'B'C'D' as shown.

Describe the transformation geometrically.

Represent the transformation algebraically.

Solution:

  • To describe the transformation geometrically, we need to observe what the quadrilateral did from the preimage ABCD to the image A'B'C'D'.
  • We notice that the vertices of the quadrilateral slide to the right AND slide up. This means it translated right a number of units AND up a number of units.
  • Now, we need to count the units from point A to point A' to see how many units right it translated.
  • We count 5 units from point A to get under point A'.
  • Next, we count how many units up we need to go to get onto A'.
  • We count 3 units up.
  • Now, we can represent this algebraically using the rule for translations.

The triangle translated right 5 AND up 3 units represented as \((x,y)\rightarrow (x+5,y+3)\). This is a double translation or a glide.



Example 4

Quadrilateral ABCD has the following vertices; \(A(-9,2)\), \(B(-7,7)\), \(C(-1,7)\), and \(D(-1,2)\).

The quadrilateral is translated to the right 7 units.

Find the coordinates of the image A'B'C'D'.

Solution:

  • Since we are translating the quadrilateral to the right 7 units, we can use the rule \((x,y)\rightarrow (x+7,y)\).
  • We will apply this rule to each of the vertices to identify the coordinates of the image.
    • Let's find A' - \(A(-9,2)\rightarrow A'(-9+7,2)=(-2,2)\)
    • \(B(-7,7)\rightarrow B'(-7+7,7)=(0,7)\)
    • \(C(-1,7)\rightarrow C'(-1+7,7)=(6,7)\)
    • \(D(-1,2)\rightarrow D'(-1+7,2)=(6,2)\)

Answer: The coordinates of A'B'C'D' are \(A'(-2,2)\), \(B'(0,7)\), \(C'(6,7)\), and \(D(6,2)\).



Example 5

Quadrilateral ABCD has the following vertices; \(A(6,1)\), \(B(4,5)\), \(C(10,5)\), and \(D(12,1)\).

The quadrilateral is translated to 5 units left and 6 units up.

Find the coordinates of the image A'B'C'D'.

Solution:

  • Since we are translating the quadrilateral left 5 units AND 6 units up, we can use the rule \((x,y)\rightarrow (x-5,y+6)\).
  • We will change the x and y coordinates. We will subtract 5 from the x-coordinate to translate it left 5 units.
  • Then we will add 6 units to the y-coordinate to move it up 6 units.
  • We will apply this rule to each of the vertices to identify the coordinates of the image.
    • Let's find A' - \(A(6,1)\rightarrow A'(6-5,1+6)=(1,7)\)
    • \(B(4,5)\rightarrow B'(4-5,5+6)=(-1,11)\)
    • \(C(10,5)\rightarrow C'(10-5,5+6)=(5,11)\)
    • \(D(12,1)\rightarrow D'(12-5,1+6)=(7,7)\)

Answer: The coordinates of A'B'C'D' are \(A'(1,7)\), \(B'(-1,11)\), \(C'(5,11)\), and \(D(7,7)\).



Example 6

Triangle ABC has the following vertices \(A(-5,-3)\), \(B(-1,4)\), and \(C(5,1)\) as shown.

Draw the image of the triangle that is translated left 3 units.

Solution:

  • We can begin by applying the rule \((x,y)\rightarrow (x-3,y)\) to each vertex of the triangle to find the new vertices.
    • \(A(-5,-3)\rightarrow A'(-5-3,-3)=(-8,-3)\)
    • \(B(-1,4)\rightarrow B'(-1-3,4)=(-4,4)\)
    • \(C(5,1)\rightarrow C'(5-3,1)=(2,1)\)
  • Now that we know the coordinates of the image, we can plot each point. Then we can connect the points to draw the triangle.



Example 7

Triangle ABC has the following vertices \(A(-8,-4)\), \(B(0,-4)\), and \(C(-5,3)\) as shown.

Draw the image of the triangle that is translated 5 units right and 4 units up.

Solution:

  • We can begin by applying the rule \((x,y)\rightarrow (x+5,y+4)\) to each vertex of the triangle to find the new vertices.
    • \(A(-8,-4)\rightarrow A'(-8+5,-4+4)=(-3,0)\)
    • \(B(0,-4)\rightarrow B'(0+5,-4+4)=(5,0)\)
    • \(C(-5,3)\rightarrow C'(-5+5,3+4)=(0,7)\)
  • Now that we know the coordinates of the image, we can plot each point. Then we can connect the points to draw the triangle.



Conclusion

In this lesson, you learned how translations can be represented using algebraic rules in the coordinate plane. Translations shift a figure using a vector and are written using the rule \((x,y)\rightarrow (x+a,y+b)\). You practiced identifying these transformations from given coordinates, writing transformation rules, and graphing new images. Mastering these skills helps you describe geometric movements precisely and prepares you for analyzing transformation sequences and congruence or similarity in future lessons.
